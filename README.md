# Aegis Mesh

複数AIを安全に働かせるための管制システム Aegis Mesh の開発リポジトリです。

## 文書構成

- `docs/正本/`
  - Aegis Mesh の正本文書を保存します。
  - 現在の正本は `【Aegis Mesh】企画概要書.md` です。
- `docs/計画/`
  - 正本をもとにした開発計画を保存します。
- `docs/ルールブック.md`
  - AI支援開発の共通運用ルールです。

今後、開発工程表・工程別実装指示書・`TASK_CURRENT.md` を計画に従って追加します。

## 正本運用

1. 正本は `docs/正本/` に置く。
2. 正本と計画書・工程表・実装指示書・TASKを混同しない。
3. 未確定事項を推測で補完しない。
4. 正本未確認のまま実装へ進まない。
5. 変更履歴はGitで追跡する。
