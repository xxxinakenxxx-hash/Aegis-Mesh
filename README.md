# Aegis Mesh

複数AIを安全に働かせるための管制システム Aegis Mesh の開発リポジトリです。

## 共通の開発ルール（最初に確認）

- [ルールブック.md](ルールブック.md) — AI開発の手順・役割・承認・正本読了・履歴・完了判定
- [GitHubリポジトリ標準規約.md](GitHubリポジトリ標準規約.md) — 正本・計画・記録・AI設定・GitHub更新管理
- `AGENTS.md` — Codex用の入口
- `CLAUDE.md` — Claude Code用の入口

両規約は**このリポジトリのルートに保存されたファイル**を使用する。ファイル名を示すだけでは読了扱いにしない。

## 文書構成

- `docs/正本/`
  - Aegis Mesh固有のプロジェクト正本文書を保存します。
  - 現在のプロジェクト正本は `【Aegis Mesh】企画概要書.md` です。
- `docs/計画/`
  - 開発工程表・未確定事項確認書など、正本を実装工程へ展開する管理文書を保存します。
工程別実装指示書は `docs/実装指示書/`、進捗履歴は `tasks/` に保存します。

## 正本運用

1. Aegis Mesh固有のプロジェクト正本は `docs/正本/` に置く。
2. 共通運用ルールはルートの `ルールブック.md` および `GitHubリポジトリ標準規約.md` を参照する。
3. プロジェクト正本と工程表・実装指示書・TASKを混同しない.
4. 未確定事項を推測で補完しない。
5. 正本未確認のまま実装へ進まない。
6. 変更履歴はGitで追跡する。
