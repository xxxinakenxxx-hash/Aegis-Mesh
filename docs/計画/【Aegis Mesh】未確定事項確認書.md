# 2. 確定済みで本書に残さない事項

以下は現行正本で確定しているため、未確定事項として管理しない。

- 実装言語：TypeScript
- 実行基盤：Vercel
- 人間向けUI：Vercel上の専用Web画面
- 正本・履歴・状態管理のベース：GitHub
- Driveを正本・実行時参照元にしない
- GitHubはAegis Mesh本体ではない
- Codexはデプロイ不可
- Claude Codeは条件付きデプロイ
- ChatGPT = 設計・管理者AI
- Codex親 = 現場監督
- Subagents = Codex親配下の実装実行系
- Claude Code = 別経路の実装実行系
- BLOCKED後は人間判断で再開 / 中止
- 完了条件未達時は自動継続を止めて再検討
- Retryは一時的失敗に対する同一処理の再試行に限定
- 人間とChatGPTが同じ基礎管制データを参照する
- CHAT_CURRENT更新確認前に後続操作を解放しない
