## U-03 自動操作の許可モデル
**確定：採用**

操作を次の3区分で管理する。

| 区分 | 扱い |
|---|---|
| 事前許可済み | 許可範囲内で自動実行可 |
| 条件付き許可 | 定義済み条件を満たす場合のみ自動実行可 |
| 範囲外 / 禁止 | 停止し、人間判断へ戻す |

工程またはタスク単位で最低限、次を持つ。

```text
scope
allowed_actions
forbidden_actions
side_effect_policy
approval_required_if
```

人間の明示承認は、個別操作ごとではなく、工程開始時の許可範囲設定でも成立する。

許可範囲内では個別再承認を要求しない。

---

## U-04 Git操作の自動許可範囲
**確定：採用**

### 自動実行可
対象リポジトリ・対象branch・対象工程・変更範囲が明示されている場合に限る。

- status / diff / log 等の参照
- 作業branch作成
- 対象ファイルの作成・更新
- commit
- 通常push
- PR作成

### 条件付き自動
- merge
  - 対象工程で許可されている
  - 必須チェックが通っている
  - BLOCKEDがない
  - 未解決事項が完了条件を妨げていない
  - 禁止事項に抵触していない

### 禁止
- force push
- 履歴改変
- repository削除
- branch削除
- 指定外repository変更
- 指定外branch変更
- 指定外ファイル変更

範囲外操作が必要になった場合は停止する。

## U-05 デプロイ・外部通信・権限変更等
**確定：採用**

### デプロイ

| 実行者 | 方針 |
|---|---|
| Codex | デプロイ禁止 |
| Claude Code | 条件付き自動デプロイ可 |

Claude Codeの自動デプロイ条件：

- 対象工程でデプロイが許可されている
- 必須テストが通っている
- 変更が許可範囲内
- BLOCKEDがない
- 禁止事項に抵触していない

### その他の外部作用

| 操作 | 方針 |
|---|---|
| 既存の承認済み外部通信先への通信 | 条件付き自動 |
| 新規外部通信先 | 人間承認 |
| 外部API追加 | 人間承認 |
| パッケージ追加 | 人間承認 |
| 認証・権限変更 | 人間承認 |
| DB / スキーマ変更 | 人間承認 |
| 既存データ削除 | 原則禁止。専用の明示指示がある場合のみ実施可能 |
