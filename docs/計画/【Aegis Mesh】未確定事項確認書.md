## 3. 承認済み方針と正本修正の留意点（2026-10-19）
- GitHubが全ての永続記録の保存先。補助ストア導入は現在の承認方針ではない。認証トークンなどの秘密情報は保存しない。
- Work Contract／Result PacketによるAI間受渡しは決定済み。実接続方法のみ検証が残る。
- 通常のAI担当選択はChatGPT、人間判断は許可範囲を越える操作などの場合のみ。
- Codexは**現在デプロイ禁止**だが、将来はチェック体制完成後に条件付き解禁を目指す。少なくとも(1)指示書にデプロイ先・対象範囲・必須テスト・禁止事項・完了条件、(2)Aegisの実行前整合、(3)Codexのテスト・Evidence、(4)デプロイ直前の環境・変更・BLOCKED・許可再確認、(5)デプロイ後検証と失敗時の停止・ChatGPT原因分析を必要とする。**正式解禁は未実施**。
- 条件付き承認の条件文書化はCodexだけでなくmerge、Claude Codeのデプロイその他の条件付き操作にも共通適用。
- 未確定のRetry間隔・回数、Failure Signature形式、接続認証、詳細スキーマは決定済み扱いしない。
